Objetivo del proyecto

Crear una presencia digital mas profesional para un negocio local, con informacion clara y una estructura preparada para crecer.

Carta digitalMenu, cocktails y chupitos con rutas propias.
Movil primeroDiseño pensado para clientes que consultan desde el telefono.
MultidiomaContenido preparado para publico local y turistas.
Gestion internaBase tecnica lista para administrar contenido.

Problema

Un bar o lounge necesita que el cliente entienda rapido que ofrece, pueda ver la carta y se lleve una primera impresion profesional antes de visitar el local.

  • Informacion importante dispersa.
  • Necesidad de consulta rapida desde movil.
  • Marca visual que debia sentirse mas cuidada online.

Solucion

Una web visual con identidad propia, paginas especificas para carta y bebidas, secciones por idioma y estructura preparada para futuras mejoras.

  • Home visual con marca clara.
  • Carta digital accesible.
  • Rutas para menu, cocktails y chupitos.
  • Base Laravel para escalar el proyecto.
Tecnologias

Construida con una base solida

El proyecto usa Laravel y Blade, con una estructura pensada para separar contenido, vistas y futuras funciones de administracion.

  • Laravel
  • Blade templates
  • SQLite
  • Vite
  • HTML y CSS responsive
