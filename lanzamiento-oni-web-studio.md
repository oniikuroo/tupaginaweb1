# Lanzamiento de Oni Web Studio

## Objetivo de los primeros 30 dias

Conseguir los primeros contactos reales de negocios locales y cerrar al menos 1 proyecto pequeno usando La Favela como caso real.

## Posicionamiento

Oni Web Studio crea webs profesionales para negocios locales que necesitan transmitir confianza, recibir contactos por WhatsApp y mostrar sus servicios con claridad.

Frase base:

> La herramienta esencial para tu negocio.

Version mas comercial:

> La web profesional que convierte visitas en clientes.

## Oferta inicial

Oferta recomendada para empezar:

- Demo visual o propuesta sin compromiso.
- Web basica desde 399 EUR.
- Web profesional desde 799 EUR.
- Mantenimiento opcional desde 49 EUR/mes.

No vendas "una pagina". Vende claridad, confianza, reservas, mensajes por WhatsApp y presencia profesional.

## Antes de publicar

- Confirmar que el Instagram es @oni.webstudio.
- Preparar 9 publicaciones iniciales para que el perfil no se vea vacio.
- Subir una foto de perfil simple con el nombre Oni Web Studio.
- Crear destacados: Webs, Casos, Proceso, Contacto.
- Poner el enlace de la web en la bio cuando tengas dominio o hosting.
- Preparar una captura real de La Favela para usarla como prueba.

## Canales

Instagram:
- Reels cortos mostrando transformaciones, ejemplos y consejos.
- Carruseles explicando errores comunes.
- Stories con avances y llamadas a WhatsApp.

Google Maps:
- Buscar restaurantes, peluquerias, clinicas, talleres y profesionales sin web o con web antigua.
- Guardar nombre, ciudad, Instagram, web actual y telefono.
- Contactar con mensaje corto y personalizado.

WhatsApp:
- Usarlo solo despues de tener una razon clara para escribir.
- Mensajes breves, con propuesta concreta.

## Plan semanal

Semana 1:
- Publicar 3 reels y 2 carruseles.
- Contactar 20 negocios locales.
- Subir stories mostrando el caso La Favela.

Semana 2:
- Contactar 30 negocios mas.
- Publicar una mini auditoria de una web.
- Crear una propuesta visual para 1 sector.

Semana 3:
- Repetir lo que mas respuestas consiga.
- Ofrecer 3 demos personalizadas.
- Pedir feedback a conocidos empresarios.

Semana 4:
- Publicar resultados: capturas, aprendizajes, procesos.
- Ajustar precios si hay interes.
- Preparar una pagina de caso real para La Favela.

## Indicadores

Mide cada semana:

- Negocios contactados.
- Respuestas recibidas.
- Llamadas o conversaciones abiertas.
- Propuestas enviadas.
- Presupuestos aceptados.

Objetivo minimo:

- 100 negocios contactados en 30 dias.
- 10 respuestas.
- 3 conversaciones serias.
- 1 cliente.
