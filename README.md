# TuWebLocal

Este paquete sirve para empezar a vender paginas web a negocios locales.

## Archivos

- `index.html`: tu web principal de agencia.
- `demos/restaurante.html`: demo para restaurantes.
- `demos/peluqueria.html`: demo para peluquerias.
- `demos/clinica.html`: demo para clinicas.
- `guia-para-vender.md`: plan, mensajes y checklist.
- `propuesta-cliente.md`: plantilla para enviar presupuestos.

## Cambios obligatorios

Busca y cambia estos textos:

- `TuWebLocal`: pon tu marca o nombre.
- `34693860908`: tu WhatsApp con prefijo.
- `Madrid`, `Valencia`, `Sevilla`: pon ciudades reales o cambia las demos.
- precios: ajustalos si quieres empezar mas barato.

## Como abrirlo

Abre `index.html` con doble clic.

Tambien puedes abrir las demos desde los botones de la pagina principal.

## Como venderlo

1. Abre Google Maps.
2. Busca negocios con mala web o sin web.
3. Envia uno de los mensajes de `guia-para-vender.md`.
4. Si responden, envia una demo del sector.
5. Si les interesa, usa `propuesta-cliente.md`.
