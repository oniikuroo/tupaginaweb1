# Checklist para publicar la web

## Dominio

Opciones de dominio:

- oniwebstudio.com
- oniwebstudio.es
- oniwebstudio.dev

Recomendado para Espana:

- oniwebstudio.es si esta libre.
- oniwebstudio.com si quieres sonar mas internacional.

## Hosting

Para esta web estatica puedes usar:

- Netlify.
- Vercel.
- GitHub Pages.
- Cloudflare Pages.

La opcion mas simple suele ser Netlify o Vercel.

## Antes de subir

- Cambiar cualquier texto provisional.
- Revisar telefono de WhatsApp.
- Revisar enlace de Instagram: https://www.instagram.com/oni.webstudio/
- Revisar que La Favela este enlazada a una URL publica si quieres mostrarla fuera de tu ordenador.
- Crear una imagen de vista previa para redes.
- Probar la web en movil.

## Despues de subir

- Poner la URL en Instagram.
- Enviar la web a 10 personas para feedback.
- Crear una publicacion de lanzamiento.
- Contactar los primeros 20 negocios.
- Medir respuestas en seguimiento-clientes.csv.

## Publicacion de lanzamiento

Texto:

Hoy lanzo Oni Web Studio, un estudio enfocado en crear webs profesionales para negocios locales.

La idea es simple: que restaurantes, peluquerias, clinicas, talleres y profesionales tengan una presencia online clara, moderna y preparada para recibir contactos.

Ya puedes ver el primer caso real y algunos ejemplos por sector.

Si tienes un negocio y quieres mejorar como te ven online, escribeme "WEB".
